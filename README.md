# Wikismart

مساعد صوتي ذكي لأندرويد للتحكم في الفيشة الذكية (LG IoT).
قُل **«ويكي»** ← ثم الأمر (**شغل** / **اطفي**) ← والتطبيق يفتح تطبيق الفيشة ويضغط زر التشغيل أو الإطفاء.

## تحميل الـ APK
1. افتح تبويب **Actions** في الريبو ← آخر Run ناجح (Build Wikismart APK).
2. نزّل الملف **Wikismart-APK** من قسم Artifacts، فك الضغط، وثبّت `Wikismart.apk` على الموبايل.

## الإعداد (مرة واحدة)
1. **الأذونات**: اضغط «السماح بالميكروفون والإشعارات».
2. **خدمة إمكانية الوصول**: اضغط «تفعيل خدمة Wikismart» ← Wikismart ← تشغيل.
   - لو الخيار رمادي (أندرويد 13+ للتطبيقات المثبتة من خارج المتجر): معلومات التطبيق ← ⋮ ← «السماح بالإعدادات المقيدة» ثم ارجع فعّلها.
3. **الظهور فوق التطبيقات**: اسمح بها (بتساعد التطبيق يفتح تطبيق الفيشة والشاشة مقفولة أو التطبيق في الخلفية).
4. **اختيار تطبيق الفيش**: اختر التطبيق اللي بتتحكم منه في الفيش (LG ThinQ أو أي تطبيق تاني).
5. **التعرف على أسماء الفيش**: اضغط «🔎 فحص التطبيق» ← التطبيق يفتح تطبيق الفيش ويقرأ قائمة الأجهزة (ويعمل Scroll) ← ترجع تلقائيًا وتظهر لك الأسماء، شيل علامة أي حاجة مش فيشة واحفظ. تقدر تضيف أو تحذف أسماء بإيدك، وتجرب كل فيشة بزر «تشغيل / إطفاء».
6. **الذكاء الاصطناعي**:
   - **محرك مدمج جاهز دايمًا بدون إنترنت**: عربي وإنجليزي، أسماء الفيش (مطابقة تقريبية)، «كل الفيش»، مؤقتات («بعد ١٠ دقايق»، «بعد نص ساعة»)، وحالة الفيشة.
   - **اختياري**: مفتاح Claude API لنموذج سحابي بيفهم الكلام بحرية، بيفتكر آخر كلامكم، وبيرد على أي سؤال (ومعاه أسماء فيشك). المفتاح بيتخزن على الموبايل فقط.
7. اضغط **«ابدأ الاستماع لكلمة ويكي»**. أمثلة: «ويكي شغل فيشة المطبخ» • «ويكي اطفي كل الفيش» • «ويكي اطفي الغسالة بعد ١٠ دقايق» • «ويكي المكواة شغالة؟»

## ملاحظات
- التعرف على الصوت بيستخدم خدمة Google، فغالبًا محتاج إنترنت. لغة الصوت (عربي/إنجليزي) من الإعدادات.
- التطبيق بيدوّر على سويتش التشغيل أو زر مكتوب عليه «تشغيل / إطفاء / On / Off» أو زر طاقة داخل تطبيق الفيشة.
- حالة الفيشة («شغالة / مطفية») هي آخر أمر نفذه التطبيق، مش قراءة حية من الفيشة. والمؤقتات بتتلغي لو أوقفت الاستماع.
- يُبنى الـ APK تلقائيًا عن طريق GitHub Actions عند كل Push على `main`.
