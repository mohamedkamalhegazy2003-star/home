# Wikismart

مساعد صوتي ذكي لأندرويد للتحكم في الفيشة الذكية (LG IoT).
قُل **«ويكي»** ← ثم الأمر (**شغل** / **اطفي**) ← والتطبيق يفتح تطبيق الفيشة ويضغط زر التشغيل أو الإطفاء.

## تحميل الـ APK
1. افتح تبويب **Actions** في الريبو ← آخر Run ناجح (Build Wikismart APK).
2. نزّل الملف **Wikismart-APK** من قسم Artifacts، فك الضغط، وثبّت `Wikismart.apk` على الموبايل.

## الإعداد (مرة واحدة)
1. **الأذونات**: اضغط «السماح بالميكروفون والإشعارات».
2. **خدمة إمكانية الوصول**: اضغط «تفعيل خدمة Wikismart» ← Wikismart ← تشغيل.
   - لو الخيار رمادي (أندرويد 13+ للتطبيقات المثبتة من خارج المتجر): معلومات التطبيق ← ⋮ ← «السماح بالإعدادات المقيدة» ثم ارجع فعّلها.
3. **الظهور فوق التطبيقات**: اسمح بها (بتساعد التطبيق يفتح تطبيق الفيشة والشاشة مقفولة أو التطبيق في الخلفية).
4. **اختيار تطبيق الفيشة**: اختر التطبيق اللي بتتحكم منه في الفيشة (LG ThinQ أو أي تطبيق تاني). لو عندك أكثر من جهاز، اكتب اسم الفيشة زي ما هو ظاهر في التطبيق.
5. **الذكاء الاصطناعي (اختياري)**: ضع مفتاح Claude API لفهم الكلام بحرية والرد عليك صوتيًا. بدون مفتاح التطبيق بيفهم أوامر شغل/اطفي محليًا. المفتاح بيتخزن على الموبايل فقط.
6. اضغط **«تجربة: تشغيل الفيشة»** للتأكد إن الضغط شغال، وبعدها **«ابدأ الاستماع لكلمة ويكي»**.

## ملاحظات
- التعرف على الصوت بيستخدم خدمة Google، فغالبًا محتاج إنترنت. لغة الصوت (عربي/إنجليزي) من الإعدادات.
- التطبيق بيدوّر على سويتش التشغيل أو زر مكتوب عليه «تشغيل / إطفاء / On / Off» أو زر طاقة داخل تطبيق الفيشة.
- يُبنى الـ APK تلقائيًا عن طريق GitHub Actions عند كل Push على `main`.
